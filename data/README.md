# Generated datasets

This directory is populated by `R/data_generation.R` with 15 synthetic CSV files:

- `alarm_*.csv`
- `hailfinder_*.csv`
- `hepar_*.csv`

Each network is sampled at n = 500, 1,000, 2,500, 5,000 and 10,000 observations. The generated CSV files are not included in this initial repository package. Run the data-generation script after placing the required fitted network RDS files in the project root.
